# 第9章 无线网络与移动网络

## 章节概述

本章覆盖无线局域网（WLAN/802.11）、无线个人区域网（WPAN：蓝牙/ZigBee）、蜂窝移动通信（2G→4G LTE）和移动IP。核心难点：**无线MAC协议（CSMA/CA）** 和 **LTE网络架构（GTP隧道）**。

---

## 9.1 无线局域网 WLAN

### 基本概念与架构

**两大类WLAN**：
1. **有固定基础设施的WLAN**（IEEE 802.11）：使用接入点AP
2. **无固定基础设施的WLAN（移动自组网络）**：无AP，节点平等

**IEEE 802.11核心构件**：

```
移动站 ←→ AP（接入点）←→ 分配系统DS（有线骨干）←→ 互联网
```

- **BSS（基本服务集）**：一个AP + 其关联的移动站
- **ESS（扩展服务集）**：多个BSS通过DS互联（支持漫游）
- **SSID（服务集标识符）**：WiFi网络名，≤32字节字符串
- **BSSID**：AP的唯一48位MAC地址（用于帧传输，非SSID）

**信道划分（2.4GHz）**：
- 802.11b/g：约85MHz带宽，11个部分重叠信道
- 相邻信道中心频率差5MHz，每信道带宽约22MHz
- 非重叠信道：1、6、11（常用配置）

### 关联过程

移动站加入BSS前必须先**关联（Associate）**：

**方法1：被动扫描**
- AP周期性广播**信标帧（Beacon Frame）**（含SSID、速率等）
- 移动站扫描11个信道，选择AP，发送**关联请求帧**
- AP回复**关联响应帧**

**方法2：主动扫描**
- 移动站广播**探测请求帧（Probe Request）**
- 所有AP回复**探测响应帧**
- 移动站选择AP，发关联请求

**安全关联**：建立关联时需验证密码（WEP已淘汰→WPA→**WPA2/WPA3**）

**重建关联（Reassociation）**：漫游时将关联转移到另一AP
**分离（Dissociation）**：终止关联

### 移动自组网络（Ad Hoc）

- 无AP，移动站处于平等状态
- 服务范围受限，通常不与外部网络相连
- 三个主要问题：路由选择协议、多播、安全
- 优点：部署灵活，生存性好
- 应用：无线传感器网络WSN（物联网IoT）

| 标准 | 年份 | 频段 | 最高速率 | 关键技术 |
|-----|-----|-----|---------|---------|
| 802.11b | 1999 | 2.4GHz | 11 Mbit/s | DSSS |

## 9.1.3 802.11 MAC层协议（CSMA/CA）

### 为什么不用CSMA/CD？

1. **碰撞检测困难**：发送时自身信号强度远大于碰撞检测所需信号
2. **隐蔽站问题（Hidden Station Problem）**：
   - A和C各自检测不到对方，都认为B空闲
   - 两者同时向B发送 → 碰撞

```
A ←(覆盖范围)→ B ←(覆盖范围)→ C
A和C互相听不见，但都能与B通信
```

### CSMA/CA工作原理

> **先听后发，碰撞避免，ACK确认，退避重传**

**DCF（分布式协调功能）**：基于争用，所有实现必须支持
**PCF（点协调功能）**：集中轮询，可选，用于时延敏感业务

**关键时间间隔**：
- **SIFS（短帧间间隔）**：最短，用于ACK、CTS、分片确认
- **DIFS**：较长，用于数据帧和管理帧的发送
- DIFS > SIFS，确保ACK帧优先于新数据帧发送

**典型发送流程**：
```
1. A监听信道
2. 信道空闲超过DIFS → A立即发送DATA
3. B收到DATA，CRC校验无误
4. 等待SIFS → B发送ACK（优先于其他站的DIFS等待）
5. A收到ACK → 成功
6. A未收到ACK → 重传（进入退避）
```

**退避算法**：
- 检测信道忙时：**推迟接入**（退避计时器冻结）
- 争用期：在 $[0, CW]$ 随机选择时隙数，倒计时
- 计时器先归零的站优先发送
- 若再碰撞：争用窗口**近似加倍**（指数退避）
- 建议：$15 \leq CW \leq 1023$，初始CW=15，第i次退避范围为 $2^{4+i}-1$

**推迟接入 vs 退避的区别**：
- 推迟接入：信道忙时等待（计时器冻结）
- 退避：信道空闲后的争用阶段（计时器倒计时）

### 信道预约（RTS/CTS）

解决隐蔽站问题，减少大帧碰撞：

```
A ──RTS(含NAV时间)──→ B
A ←──CTS(含NAV时间)── B
（C收到CTS后设置NAV，在NAV期间不发送）
A ──DATA──→ B
A ←──ACK── B
```

- **NAV（网络分配向量）**：虚拟载波监听，指示信道被占用的时长
- RTS/CTS不是强制的，只有数据帧超过阈值时才值得使用
- RTS=20字节，CTS=14字节，大帧最大2346字节

## 9.1.4 802.11 MAC帧格式

```
帧控制(2B)|持续期(2B)|地址1(6B)|地址2(6B)|地址3(6B)|序号控制(2B)|地址4(6B)|数据(0~2312B)|FCS(4B)
```

**三种帧类型**：控制帧、数据帧、管理帧

**四个地址字段的含义**（最常用两种情况）：

| 场景 | 去往AP=1, 来自AP=0 | 去往AP=0, 来自AP=1 |
|-----|------------------|------------------|
| **地址1** | AP的MAC（接收方）| 目的站MAC（接收方）|
| **地址2** | 源站MAC（发送方）| AP的MAC（发送方）|
| **地址3** | 目的站MAC | 源站MAC |

**帧控制字段**（11个子字段）：协议版本、类型/子类型、更多分片、重试、功率管理、WEP加密标志等

**分片**：信道质量差时，将长帧分成多个短片，减少重传开销（使用SIFS+ACK确认每个分片）

## 9.2 无线个人区域网 WPAN

### WPAN vs WLAN

| 特性 | WPAN | WLAN |
|-----|-----|-----|
| 服务对象 | 个人（1人） | 多用户 |
| 范围 | ~10m | ~100m |
| 功耗 | 极低 | 中 |
| 速率 | 低~高 | 高 |
| 标准 | IEEE 802.15 | IEEE 802.11 |

### 蓝牙（Bluetooth，802.15.1）

- 1994年爱立信推出，工作于**2.4GHz ISM频段**
- 使用**跳频扩频（FHSS）**，抗干扰

**皮可网（Piconet）**：
- 1个主设备（Master）+ 最多**7个**活跃从设备（Slave）+ 最多255个停放设备
- 主设备控制时隙分配（TDM）

**扩散网（Scatternet）**：多个皮可网通过共享主/从设备互连

**蓝牙4.0低功耗BLE（Bluetooth Low Energy）**：
- 适合数据量极小的传感器
- 电池可用4-5年
- 距离扩展到30m，速率可达1 Mbit/s

### ZigBee（802.15.4）

- 低速（2~250 kbit/s）、低功耗、低成本
- 电池寿命可超**10年**（工作比例<1%）
- 网络容量大：单网255个节点，通过协调器超过**64000个节点**
- 通信距离：10~80m

**两类设备**：
- **FFD（全功能设备）**：充当协调器，维护网络节点信息
- **RFD（精简功能设备）**：只与协调器通信，简单终端

**ZigBee与802.15.4的关系**：
- 802.15.4定义物理层和MAC层
- ZigBee联盟定义网络层和应用层

### 高速WPAN（802.15.3）

- 11~55 Mbit/s，用于便携多媒体设备间传送
- UWB（超宽带）技术：3.1~10.6 GHz，带宽>500MHz

## 9.3 蜂窝移动通信网

### 代际演进

| 代际 | 年代 | 代表技术 | 主要特点 | 接入技术 |
|-----|-----|---------|---------|---------|
| **1G** | ~1978 | AMPS | 模拟话音 | FDMA |
| **2G** | ~1990 | GSM | 数字话音+SMS | FDMA/TDMA |
| **2.5G** | ~1999 | GPRS | 分组数据（171.2 kbit/s）| - |
| **3G** | ~2000 | WCDMA/TD-SCDMA/CDMA2000 | 移动宽带（2 Mbit/s）| CDMA |
| **4G/LTE** | ~2008 | LTE/LTE-A | 全IP化，百Mbit/s | OFDMA/SC-FDMA |
| **5G** | ~2019 | NR | 超低延迟，万物互联 | OFDMA+Massive MIMO |

### GSM（2G）重要组成

- **小区（蜂窝）**：整个覆盖区分为多个小区
- **频率复用**：相邻小区用不同频率，避免同频干扰
- **空口**：FDMA/TDMA混合（25MHz分125个200kHz子频带，每子频带8个TDM时隙）
- **电路交换**：提供话音服务
- 核心网：基站→基站控制器BSC→移动交换中心MSC→网关MSC

**GPRS（2.5G）引入分组交换**：
- 添加PCU（分组控制单元）和SGSN/GGSN节点
- 支持最高171.2 kbit/s（GPRS）和384 kbit/s（EDGE）

### 我国3G三种标准
- **WCDMA**（中国联通）：3GPP欧洲标准
- **CDMA2000**（中国电信）：3GPP美国标准
- **TD-SCDMA**（中国移动）：3GPP主要由中国提出

### LTE（4G）体系结构

**IMT-Advanced最重要特点**：取消电路交换，**全部使用分组交换（全网IP化）**

**LTE（3GPP R8，3.9G）**：信道带宽20MHz时，下行100 Mbit/s，上行50 Mbit/s

**LTE提高速率的方法**：
- 下行：**OFDMA（正交频分多址）**
  - 多子载波并行传输，子信道频谱重叠但正交（不产生干扰）
  - 减少多径效应引起的符号间干扰
- 上行：SC-FDMA（单载波频分多址）
- **MIMO（多天线）**
- 高阶调制：64 QAM
- **AMC（自适应调制编码）**：基站eNB根据信道反馈动态调整调制方式

**LTE网络结构（扁平化）**：
```
UE（手机）←→ eNB（基站）←→ S-GW ←→ P-GW ←→ 互联网
                              ↑
                             MME（控制面：鉴权、移动性管理）
```

- E-UTRAN（演进的无线接入网）：只有eNB
- EPC（演进的分组核心网）：MME + S-GW + P-GW
- eNB之间可直接通信（X2接口），无需经过核心网

**GTP隧道（GPRS隧道协议）**：
- UE→eNB：无线空口链路
- eNB→S-GW：GTP-U隧道（用TEID标识）
- S-GW→P-GW：GTP-U隧道
- 每个GTP分组有TEID（隧道端点标识符）标识属于哪个UE

**UE空闲态节能机制**：
- 释放：UE和eNB间空口链路 + eNB与S-GW间GTP隧道
- 保持：S-GW与P-GW间隧道 + UE的IP地址不变（只要UE不超出P-GW覆盖范围）

**LTE寻呼（UE处于空闲态）**：
- **跟踪区TA（Tracking Area）**：位置管理基本单位
- **跟踪区列表TAL**：1-16个TA，UE在TAL内漫游不需向MME报告
- MME只在TAL范围内的eNB广播寻呼，不是全网广播

**LTE漫游切换**：
- UE持续测量小区信号强度上报eNB
- eNB发现更好的小区→触发切换
- 切换时S-GW和P-GW间的GTP隧道通常**不重建**（S-GW覆盖范围大）
- 切换过程中数据通信**不中断**

## 9.4 移动IP

### 基本概念

**问题**：移动节点更换网络时IP地址改变，TCP连接中断。

**解决方案**：让移动节点保留**归属地址（永久地址）** 不变，由**归属代理**做地址转发。

**核心概念**：

| 概念 | 说明 |
|-----|-----|
| **归属地址** | 移动节点的永久IP地址 |
| **归属网络** | 移动节点原始所在网络 |
| **归属代理（Home Agent）** | 归属网络的路由器，代理转发 |
| **被访网络（外地网络）** | 移动时所在的新网络 |
| **外地代理（Foreign Agent）** | 被访网络的路由器 |
| **转交地址（CoA）** | 移动节点在外地网络的临时地址 |

### 通信者B向移动站A发送数据（间接路由/三角路由）

```
① B发送数据报，目的地址=A的归属地址
② A的归属代理HA截获数据报
③ HA将数据报**再封装**（新目的=转交地址CoA），用隧道发给外地代理FA
④ FA拆封，用A的归属地址转发给A
⑤ A直接用归属地址发送回给B（不经过HA）
```

**三角路由问题**：B→HA→FA→A路径可能远不如B→A直接路径高效。

### 直接路由选择（优化）

让B的**通信者代理（Correspondent Agent）**向HA查询A的转交地址，然后直接用隧道发送：

```
B的代理 →（查询）→ HA → 获得A的锚外地代理FA1的地址
B的代理 →（隧道）→ FA1（锚外地代理）→ A
```

**锚外地代理（Anchor Foreign Agent）**：A首次漫游到的外地代理，即使A继续漫游，数据仍先到FA1，FA1再转发到A的当前位置。

### 网络层新增功能

1. 移动站到外地代理的协议
2. 外地代理到归属代理的登记协议
3. 归属代理数据报封装协议（IP-in-IP隧道）
4. 外地代理拆封协议

### 移动性对高层协议的影响

- **切换期间TCP报文段丢失** → TCP误判为拥塞 → 减小拥塞窗口 → 发送速率降低

**三种处理方法**：
1. **本地恢复**：差错在哪里就在哪里纠正（如无线局域网ARQ）
2. **通知TCP发送方**：让TCP知道哪段是无线链路，只在有线部分的丢失才触发拥塞控制
3. **拆分TCP连接**：移动用户→无线接入点是一个TCP连接，接入点→对方是另一个TCP连接
