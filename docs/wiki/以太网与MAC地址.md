# 以太网与MAC地址

## 以太网发展历程

- **1976年**：Metcalfe & Boggs 在Xerox PARC发明（10 Mbit/s, 同轴电缆）
- **1980年**：DEC、Intel、Xerox联合发布以太网规范（DIX标准）
- **1983年**：IEEE 802.3标准正式发布
- **现代**：从10M → 100M（快速以太网）→ 1G → 10G → 100G → 400G

## MAC帧格式（IEEE 802.3）

```
┌──────────┬──────┬──────┬──────┬─────────────────┬──────┐
│  前导码   │目的MAC│源MAC │类型  │     数据        │ FCS  │
│  8字节   │ 6字节 │6字节 │2字节 │  46~1500字节    │4字节 │
└──────────┴──────┴──────┴──────┴─────────────────┴──────┘
```

- **前导码**：7字节`10101010`+1字节`10101011`，用于接收方时钟同步
- **类型字段**：指示上层协议（0x0800=IPv4, 0x86DD=IPv6, 0x0806=ARP）
- **最短帧**：64字节（不含前导码），数据不足46字节需**填充**
- **最长帧（MTU）**：1500字节

## MAC地址

**格式**：48位（6字节），用连字符或冒号分隔十六进制表示

```
例：00-1A-2B-3C-4D-5E 或 00:1A:2B:3C:4D:5E
```

**结构**：

| 位 | 含义 |
|----|-----|
| 第1字节第0位(I/G位) | 0=单播地址，1=组播/广播地址 |
| 第1字节第1位(G/L位) | 0=全球唯一(OUI分配)，1=本地管理 |
| 前3字节(OUI) | 厂商标识符（IEEE分配）|
| 后3字节 | 厂商自行分配 |

**特殊地址**：
- 广播：`FF-FF-FF-FF-FF-FF`（全1）
- 本地环回：无（MAC层没有环回地址）

## MAC地址 vs IP地址

| 属性 | MAC地址 | IP地址 |
|-----|---------|-------|
| 层次 | 数据链路层 | 网络层 |
| 长度 | 48位 | 32位（IPv4）|
| 分配 | 固化在网卡，全球唯一 | 按网络拓扑动态分配 |
| 作用范围 | 本地局域网段 | 全球互联网 |
| 解析 | 人工配置/广播 | ARP协议 |

> **类比**（课件思想）：IP地址如同"邮政地址"（可变，描述位置），MAC地址如同"身份证号"（固定，描述身份）。
