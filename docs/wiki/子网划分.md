# 子网划分

子网划分（Subnetting）是从IP地址的**主机号部分**借若干位作为**子网号**，将一个大网络分割为多个较小的子网络。

## 基本概念

**子网掩码（Subnet Mask）**：连续的1对应网络/子网号，连续的0对应主机号。

```
IP地址:   192.168.1.100   = 11000000.10101000.00000001.01100100
子网掩码:  255.255.255.0   = 11111111.11111111.11111111.00000000
网络地址:  192.168.1.0     = IP AND 子网掩码
```

## 计算方法

借 $k$ 位做子网号时：
- 子网数量：$2^k$（有时减去全0和全1子网）
- 每子网主机数：$2^{n-k} - 2$（$n$ 为原主机号位数，减去网络地址和广播地址）

**例**：192.168.1.0/24 划分为 /26

```
借2位：4个子网，每子网62台主机
192.168.1.0/26   (0~63,   主机1~62)
192.168.1.64/26  (64~127, 主机65~126)
192.168.1.128/26 (128~191,主机129~190)
192.168.1.192/26 (192~255,主机193~254)
```

## VLSM（可变长子网掩码）

不同子网可以使用不同的掩码长度，充分利用地址空间：

```
总分配：10.1.0.0/24
  部门A（120台）：10.1.0.0/25   (128个地址)
  部门B（60台）：10.1.0.128/26 (64个地址)
  部门C（30台）：10.1.0.192/27 (32个地址)
  链路（2台）：  10.1.0.224/30 (4个地址)
```

## CIDR 路由聚合

反向操作：将多个子网聚合为一条路由（超网）：

```
192.168.0.0/24 ┐
192.168.1.0/24 ├─→ 192.168.0.0/22 (路由聚合)
192.168.2.0/24 │
192.168.3.0/24 ┘
```

**条件**：相邻地址块，且高位相同。
